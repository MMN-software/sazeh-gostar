# Sazeh Gostar Pars — Construction Company Website

A marketing website for a building contractor offering construction, renovation and interior design services, written in **vanilla HTML, CSS and JavaScript**. The interface is fully Persian and right-to-left.

## Features

- Industrial-style visual design aimed at lead generation
- **Services section** covering six specialist services
- **Project portfolio** with category filters and individual project detail pages
- **Four-step process** section, team profiles and client testimonials
- **Consultation request form** with validation
- Animated statistics counters and scroll-reveal effects
- Responsive layout with full RTL support

## Run locally

No build step. Open `index.html`, or:

```bash
npx serve .
```
